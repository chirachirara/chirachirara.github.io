# chirachirara

Личная картотека идей и текстов. Интерфейс основан на прототипе «нить.»; оригинал сохранён в `prototype.html`.

## Локальный запуск

Требуется Node.js 20.19+ или 22.12+.

```sh
npm install
cp .env.example .env.local
npm run dev
```

В `.env.local` укажи URL отдельного проекта Supabase и его **publishable key**. Не используй secret/service_role key: всё с префиксом `VITE_` попадёт в браузер. Публичный ключ безопасен только вместе с включёнными правилами доступа RLS.

Проект базы для этой рабочей копии уже настроен: `cnvlrimdkbjflfwnnlzm`.

## Настройка нового проекта Supabase

1. Создай проект Supabase.
2. Выполни `supabase/migrations/202610200001_initial.sql` в SQL Editor один раз. Транзакция создаёт таблицы, RLS и **закрытый** bucket `references`.
3. В Authentication → URL Configuration добавь `http://127.0.0.1:5173/` в Redirect URLs. Для публикации добавь адрес сайта; Site URL также должен указывать на сайт.
4. В Authentication включи email/password. Подтверждение почты поддерживается. Для реальной рассылки настрой собственный SMTP и проверь лимиты провайдера.
5. Заполни `.env.local` и перезапусти dev server.
6. Открой приложение, создай аккаунт, подтверди почту и войди.

Проекты и заметки по умолчанию принадлежат `auth.uid()`. RLS запрещает доступ к чужим записям; составной внешний ключ запрещает прикреплять свою заметку к чужому проекту. Доступ к изображениям ограничен папкой владельца, для показа выдаются временные ссылки.

## Что реализовано

- Вход, регистрация, восстановление пароля и выход.
- Личные проекты: замысел, основной текст, ссылка на публикацию.
- Заметки без проекта и перемещение между проектами.
- Поиск, избранное и теги текущего раздела/проекта. Сортировка переключается между недавними, названием и избранными сначала.
- Живой счётчик слов и знаков с пробелами для заметок и основного текста.
- Переход из заметки в проект по его названию.
- Скачивание сохранённого основного текста проекта в UTF-8 `.txt`.
- Мысли на полях, ссылки, до четырёх закрытых изображений на заметку.
- Корзина с восстановлением.
- Независимые локальные черновики, сохраняемые при вводе, отдельно для каждого аккаунта и редактора. Кнопка «Продолжить черновик» открывает список. Каждый черновик **не синхронизирован** до нажатия «Сохранить в базе». Пароли и основной архив приложение самостоятельно не сохраняет в localStorage; сессию авторизации хранит SDK Supabase.
- Проверка ревизии при изменении: устаревшая вкладка не перезапишет более новую версию. Если обнаружен конфликт, можно сохранить отдельную копию.
- Экспорт и импорт JSON с изображениями, включая импорт старого прототипа.

## Проверки

```sh
npm test
npm run build
npm run format:check
```

`supabase/access-test.sql` проверяет RLS, запрет подмены владельца, связь с чужим проектом, защиту от устаревшей записи и восстановление заметки. Запускай в SQL Editor: тестовые строки создаются внутри транзакции и откатываются. Если запрос упал внутри транзакции, выполни `rollback;` перед повтором.

Для сквозной проверки: создать проект → сохранить заметку → перезагрузить → проверить текст → переместить заметку в «Без проекта» → удалить в корзину → восстановить. Во втором аккаунте архив должен быть пустым. Проверить основной текст и ссылку публикации, импорт и экспорт, сбой сети при сохранении и открытие локального черновика после перезагрузки.

## Публикация на GitHub Pages

Сайт: https://chirachirara.github.io/ . Репозиторий: `chirachirara/chirachirara.github.io`.

Сборка статическая: `npm run build` создаёт `dist/`. Workflow `.github/workflows/pages.yml` проверяет тесты и форматирование, затем собирает и публикует приложение при обновлении `main`. В Settings → Pages выбран GitHub Actions.

`.env.production` содержит только публичные URL и publishable key Supabase: они входят в браузерный JS. Правила RLS и закрытое хранилище ограничивают доступ владельцем аккаунта. `.env.local`, secret/service_role key, пользовательские архивы и пароли не публикуются.

Site URL в Supabase Auth: `https://chirachirara.github.io/`. В Redirect URLs разрешены этот адрес и локальный `http://127.0.0.1:5173/`.

На опубликованном сайте войди в тот же аккаунт: сохранённые проекты и заметки доступны из общей базы Supabase. Локальные несохранённые черновики привязаны к адресу сайта и сами с localhost не переносятся — сначала сохрани их в базе.

## Ограничения первой версии

- Обновление архива с другого устройства — кнопкой «Обновить архив»; совместного редактирования и live-sync пока нет.
- Основной текст — один обычный текстовый документ на проект, без глав и rich text.
- Удаление проекта и окончательное удаление заметок пока не предусмотрены.
- Картинки, загруженные в отменённый черновик или убранные из заметки, остаются в закрытом хранилище. Автоматической очистки неиспользуемых файлов пока нет.
- Импорт добавляет копии. При сетевом сбое часть записей может быть уже импортирована; приложение сообщает количество. Импорт не атомарный.
- Локальные черновики остаются на устройстве после выхода, но открываются в интерфейсе только при входе тем же аккаунтом. На общем устройстве учитывай это при работе с личными текстами.
